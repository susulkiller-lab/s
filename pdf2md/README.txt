PDF → Markdown 변환기 (스캔 PDF 지원)

1. 처음 한 번
   - Python 3.10 이상이 있어야 합니다. https://www.python.org/downloads/ 에서 설치하고
     설치 첫 화면에서 "Add python.exe to PATH"를 체크하세요.
   - pdf2md.bat를 더블클릭합니다. 필요한 프로그램과 OCR 모델을 자동으로 설치합니다.
     인터넷이 필요하고 수 분 걸립니다. 이후에는 인터넷 없이 동작합니다.

2. 쓰는 법
   - 방법 A: pdf2md.bat를 더블클릭 → 브라우저 화면이 열립니다 → PDF를 끌어놓습니다.
     결과를 화면에서 보고 [복사] 또는 [md 저장]을 누릅니다. 여러 파일을 한꺼번에 놓아도 됩니다.
     작업이 끝나면 검은 창을 닫으면 종료됩니다.
   - 방법 B: PDF 파일을 pdf2md.bat 아이콘 위에 끌어다 놓습니다.
     각 PDF와 같은 폴더에 같은 이름의 .md 파일이 만들어집니다(기존 파일은 덮어쓰지 않고 (1), (2)를 붙입니다).

3. 동작 방식
   - 텍스트가 들어 있는 PDF: markitdown으로 변환합니다.
   - 스캔 PDF(이미지뿐인 쪽): OCR(RapidOCR 한글 모델)로 글자를 읽습니다. 쪽당 수 초가 걸립니다.
     결과에는 [1쪽], [2쪽] 표시가 붙습니다. 큰 가운데 정렬 줄은 ## 제목으로 바뀝니다.
   - 한 PDF 안에 텍스트 쪽과 스캔 쪽이 섞여 있으면 쪽마다 알맞은 방법을 씁니다.
   - 문서는 이 PC 안에서만 처리되고 외부로 전송되지 않습니다. 업로드 임시 파일은 변환 직후 지웁니다.

4. 알아 둘 한계
   - OCR 결과의 숫자, 금액, 날짜, 이름은 반드시 원본과 대조하세요. 신뢰도가 낮은 줄이 있으면 화면에 쪽 번호로 알려 줍니다.
   - 표, 다단 편집, 도장·손글씨는 정확히 옮기지 못합니다. 문단 나누기는 줄 길이와 들여쓰기로 추정하므로 어긋날 수 있습니다.
   - 암호가 걸린 PDF는 암호를 해제한 뒤 올려야 합니다.

5. 문제 해결
   - "No module named 'markitdown'" 같은 오류 또는 "패키지가 이 Python에 설치되어 있지 않습니다" 안내:
     pdf2md.py를 직접 실행했거나 설치가 중간에 끊긴 경우입니다. 반드시 pdf2md.bat로 실행하세요.
     pdf2md.bat는 실행할 때마다 필요한 패키지를 확인하고 없으면 다시 설치합니다.
     그래도 안 되면 .venv 폴더를 지우고 pdf2md.bat를 다시 실행하세요.
     검은 창 맨 위에 "Python: 경로" 줄이 나옵니다. 그 경로가 폴더 안 .venv\Scripts\python.exe가 아니면 다른 Python으로 실행된 것입니다.
   - "OCR 모델을 불러오지 못했습니다": 최초 1회 인터넷 연결이 필요합니다. 연결 후 pdf2md.bat를 다시 실행하세요.
     회사 보안망에서 막히면 모델 내려받기 주소(www.modelscope.cn) 허용을 요청하세요.
   - 설치를 처음부터 다시 하려면 .venv 폴더를 지우고 pdf2md.bat를 다시 실행합니다.

명령줄: python pdf2md.py 파일.pdf [--no-ocr] [--no-page-marks] [--out 폴더]
시험:   python -m unittest test_pdf2md -v   (reportlab, pillow, pypdf 필요)
