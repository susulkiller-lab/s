    수동 단계

    프롬프트를 복사해 Claude 대화창에 넣고, 돌려받은 JSON을 아래에 붙여 넣습니다. 자동 검사는 이 페이지가 그대로 합니다.

    확인 패널 · 작성 전에 정할 것

    '제안대로 바로 작성'은 입력한 내용을 무시하고 제안 표현을 적용하며 조문·판례는 뺍니다. 리포트에 '확인 생략'으로 남습니다.
    원 자료가 이 브라우저에 없어 '작성 다시'와 재검사는 쓸 수 없습니다.

    저장함

    작업은 단계마다 자동 저장됩니다. 결과 원고와 검사 결과는 팀 공용 저장함에, 블로그 원고·사건 기록·사실 목록은 작업한 브라우저에만 남습니다.

    사용법

    블로그에 올린 성공사례 글을 붙여 넣으면, 홈페이지 '주요 업무사례'에 올릴 글을 새로 쓰고 문제를 검사해 줍니다. 검사하는 것은 근거 없는 수치·처분명, 광고 규정 위반, 사건 관계인 노출, 블로그와 지나치게 비슷한 문장입니다. 블로그 문장을 고쳐 쓰는 방식이 아니라, 사실만 뽑아 처음부터 다시 씁니다.

    처음 한 번만: 설정 채우기 편집자

    1. 변호사 목록: '+ 변호사 추가'를 눌러 이름·직함·프로필 URL·등록 전문분야를 칸에 적고 저장합니다. 여기 넣은 변호사가 작업 화면의 '담당 변호사'에 나옵니다.
    2. 게시된 사례 목록: 홈페이지에 이미 올라간 업무사례 글입니다. 새 글 제목이 기존 글과 겹치는지 검사하고, 글 끝 '관련 링크'에 같은 분류의 사례를 고르는 데 씁니다. 엑셀에 A열 제목, B열 URL, C열 분류를 적고 행을 복사해 붙여 넣은 뒤 '일괄 등록'을 누릅니다.
    3. 법률정보 목록: 홈페이지 법률정보 글입니다. '관련 링크'에 같은 쟁점의 글을 고르는 데 씁니다. 엑셀 A열 제목, B열 URL, C열 분류, D열 태그(쉼표로 구분), E열 상태(게시 또는 테스트)로 같은 방법으로 넣습니다. 테스트 글은 링크에서 뺍니다.
    4. 사무소 정보: 주소를 넣고 저장합니다. 업무분야 URL은 미리 들어 있습니다.

    목록이 비어 있어도 작업은 됩니다. 제목 중복 검사와 관련 링크만 빠집니다.

    글 한 편 만들기

    1. 작업 탭의 '블로그 성공사례 원고' 칸에 블로그 글 전체를 붙여 넣습니다.
    2. 분야(모르면 '자동')와 담당 변호사를 고릅니다.
    3. 공개 설정을 고릅니다. 의뢰인이 공개에 동의했는지, 관할(법원·검찰청·경찰서 이름)과 결과 시점을 쓸지 정합니다. 동의가 '미확인'이거나 이혼·성범죄·아동·학대·소년·학교폭력 사건이면 관할과 시점은 저절로 빠집니다.
    4. 판결문·처분통지서에서 확인한 사실이 있으면 '사건 기록 확인 사실' 칸에 한 줄에 하나씩, 끝에 출처를 붙여 적습니다. 예) 검찰이 불기소(혐의없음) 처분을 함 [처분통지서]. 블로그보다 정확한 글이 됩니다.
    5. 같은 사건을 다룬 다른 글(네플라 등)이 있으면 '다른 채널 원고'에 넣습니다. 비슷한지 비교만 하고 글에는 쓰지 않습니다.
    6. 실행을 누릅니다. 처음에는 Claude 사용을 허락하는 창이 뜹니다. 사용량은 각자의 claude.ai 계정에서 나갑니다. '진행' 칸에서 지금 어느 단계인지 보이고, 멈추려면 '중지'를 누릅니다.

    확인 패널이 뜨면

    사람이 정해야 할 것이 있을 때만 작성 전에 멈추고 뜹니다. 번호 카드마다 할 일이 적혀 있습니다.

    • 결과의 정식 명칭: 처분통지서·판결문에 적힌 그대로 씁니다. 예) 불송치(혐의없음) 결정
    • 관계인을 알아볼 수 있는 표현: 홈페이지에 쓸 말로 고치거나 '아예 빼기'를 체크합니다.
    • 조문·판례: 원문과 대조해 확인한 것만 체크합니다. 체크하지 않으면 글에서 뺍니다.
    • 원고와 기록이 다른 부분: 어느 쪽으로 쓸지 고릅니다.
    • 요약표 빈칸: 아는 값을 적습니다. 비워 두면 '확인 필요'로 나갑니다.

    다 정했으면 이대로 작성을 누릅니다.

    결과 보고 고치기

    • 맨 위 띠가 결론입니다. 빨간 띠에 '고칠 것 n건'이 있으면 '첫 번째 고치기'를 누르면 그 칸으로 갑니다. 초록 띠 '위반 없음'이면 올려도 되는 상태입니다.
    • 미리보기: 홈페이지에 올라갈 모습입니다.
    • 수정·복사: 흰 칸에서 바로 고칩니다. 칸 밖을 누르면 반영되고 다시 검사합니다. 칸 아래 빨간 줄은 꼭 고칠 것, 노란 줄은 살펴볼 것, 초록 줄은 검수 의견입니다. 초록 줄의 '제안 적용'을 누르면 제안대로 바뀝니다. 회색 칸은 흰 칸에서 자동으로 만들어지니 고치지 않아도 됩니다.
    • 검증 리포트: 항목별 결과입니다. '고치기'를 누르면 해당 칸으로 갑니다. 아래 '게시 전 확인' 7개는 사람이 직접 확인하고 체크합니다.
    • 원문 대조: 노란 글자가 블로그 글과 똑같은 부분입니다.

    결과 아래 버튼으로 다시 쓸 수 있습니다. '작성 다시'는 같은 사실로 새로 쓰고, '지적 반영 다시'는 지적만 다시 고쳐 쓰고, '확인 패널 다시 열기'는 정식 명칭 같은 결정을 바꿔 다시 씁니다. 직접 고친 내용이 있으면 한 번 더 눌러야 실행되고, 실행 뒤에도 '다시 쓰기 전으로 되돌리기'로 돌아갈 수 있습니다.

    홈페이지에 올리기

    1. 맨 위 띠가 '위반 없음'인지, 검증 리포트의 '게시 전 확인' 7개를 다 체크했는지 봅니다.
    2. 수정·복사 탭에서 칸마다 '복사'를 눌러 홈페이지 관리자 화면에 붙여 넣습니다. 관리자 화면이 HTML을 받으면 맨 아래 '다른 형식'을 펼쳐 씁니다.
    3. 올린 뒤 결과 아래 칸에 그 글의 주소(URL)를 넣고 게시 URL 기록을 누릅니다. 게시된 사례 목록에도 저절로 추가됩니다.
    4. 블로그 연결 문구 복사를 눌러 블로그 원글 끝에 붙입니다.

    저장함

    • 작업은 단계마다 저절로 저장됩니다. 창을 닫았다 다시 열면 '마치지 못한 작업' 안내가 뜨고, '열기' 다음 '이어서 진행'을 누르면 멈춘 곳부터 다시 합니다.
    • 상태는 작성 중, 작성 완료, 게시됨 셋입니다. '열기', '게시 URL 기록', '삭제'를 쓸 수 있고, 삭제는 두 번 눌러야 지워집니다.
    • 블로그 원고와 사건 기록은 작업한 컴퓨터의 브라우저에만 남습니다. 다른 컴퓨터에서 열면 보기·고치기·복사만 되고, 다시 쓰기와 재검사는 작업한 컴퓨터에서 합니다.

    막힐 때

    • '수동 모드'로 바뀜: 이 화면에서 Claude를 바로 부를 수 없을 때입니다. 단계마다 '프롬프트 복사' → claude.ai 새 대화에 붙여 넣기 → 받은 답 전체를 '결과 JSON' 칸에 붙여 넣고 '결과 적용'. 최대 4번 반복합니다.
    • 저장이나 기록이 안 됨: 공유받은 권한이 '참여자' 이상이어야 합니다. 설정을 고치려면 '편집자'여야 합니다.
    • 'JSON으로 읽지 못했습니다': '다시 시도'를 누릅니다. 되풀이되면 원고에서 홍보 문단·연락처·해시태그를 지우고 다시 실행합니다.
    • '근거 구절이 맞지 않아 멈췄습니다': 실행을 다시 누릅니다.
