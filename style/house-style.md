# 팀 문체 규칙

상태: 임시본. 팀 글 코퍼스(corpus/posts/)를 수집하면 편집장이 '코퍼스 실측' 절을 채우고 임시 규칙을 실측값으로 바꾼다. 임시 규칙은 legal-blog-writer 스킬(v1.0)의 기준을 옮긴 것이다.

## 공통(임시)
- 경어체(-습니다/-입니다) 기본. 핵심 강조에서만 짧은 단문 허용.
- 법률 용어는 처음 나올 때 괄호로 일상어를 붙인다. 예: 채무불이행(약속한 돈을 갚지 않는 것).
- 번역투·일본어투 배제: "~에 있어서" → "~에서", "~하는 것이다" → "~합니다".
- 낚시성 수식어("충격적인", "반드시 알아야 할") 금지. 공포 마케팅 금지.
- 정보를 아끼지 않는다. "자세한 건 상담받으세요"로 끊지 않고 기한·서류·절차를 구체적으로 적는다.
- CTA는 절제한다. 예: "비슷한 상황이라면 자료를 정리해 상담을 받아 보시길 권합니다."

## 채널별 각도(임시)
- 네이버 블로그: 사례 도입 → 문제 정의 → 법률 근거 → 사례 적용 → 실무 절차 → 자주 묻는 질문 → 마무리. 모바일 가독성 우선, 3~4문장마다 문단 분리.
- 로톡: 질문에 먼저 답하는 결론 선행형. 절차·비용·기간 정보 비중을 높인다.
- 티스토리: 판례·법리 해설형. 구글 검색 유입을 고려해 소제목을 정보 요약형으로 쓰고 정의·요건을 명확히 정리한다.
