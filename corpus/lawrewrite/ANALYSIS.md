# 로리라이트(lawrewrite.com) 화면 분석

자료: 2026-09-28 사용자 제공 화면 캡처 4장. 사이트 직접 접속은 이 환경의 네트워크 정책으로 막혀 있어 확인하지 못했다. 아래 '추정'은 화면에서 유추한 것이다.

## 입력 항목(화면 확인)
- 플랫폼: 네이버 블로그 / 티스토리 / 유튜브 / 홈페이지
- 전문분야: 71개, 대분류별 칩 선택. 민사 및 부동산(민사법, 손해배상, 채권추심, 부동산, 임대차관리, 건설, 재개발·재건축, 교통사고, 의료, 환경, 국가계약, 종교, 민사집행, 등기·경매), 형사 및 공법(형사법, 군형법, 헌법재판, 행정법, 언론·방송통신, 병역), 상사 및 금융(상사법, 회사법, 인수합병 등)
- 관련법: 선택형
- 제목, 타겟 키워드 1개
- 참고 법령(펼침), 판례 파일 첨부(펼침)

## 기능 버튼(화면 확인)
생성하기, 리프레이즈(유사성·표절률 낮춤), 금칙어 체크, 정책위반, 밀도분석, 표절체크, AI 생성 감지, AI 이미지. 본문 글자 수 표시 "0 / 2,500 자".

## 보조 패널(화면 확인)
- 금칙어 감지, 정책 위반 체크, 키워드 밀도 분석, 표절 분석, AI 생성 감지 결과 카드
- 변호사광고 규정 안내: 과대·허위광고, "최고·1등·100%·보장" 표현, 소송 결과 보장, 비방·비교, 수임료 표시·무료상담 미끼 광고 금지. 화면에 제5~9조로 표기되어 있으나 어느 규정의 조문인지 확인하지 않았다(대한변호사협회 변호사업무광고규정으로 추정).
- 키워드 탭: 네이버 / 구글 / AI 키워드, 네이버 키워드 실시간 검색량 조회
- 경고문: 생성된 콘텐츠는 담당 변호사 검토 후 게시

## 생성 방식(추정)
입력값(플랫폼, 분야, 관련법, 제목, 키워드, 첨부 법령·판례)을 하나의 프롬프트 템플릿에 넣어 한 번에 본문을 생성하고, 검사 기능은 생성 뒤 버튼별로 따로 돌리는 구조로 보인다. 글자 수 상한 2,500자로 보아 짧은 정보글 기준이다.

## 원고실(app/wonkosil.html)에 반영한 것과 다른 점
- 반영: 플랫폼·분야·키워드·참고 법령 입력, 생성하기, 리프레이즈, 금칙어·광고규정·밀도·유사도 검사, 광고 기준 안내, 변호사 검토 경고
- 다른 점: 한 번 생성이 아니라 편집장 흐름(설계 → 법령 원문 확인 → 집필 → 검수 → 수정 최대 2회 → 최종 확인)으로 진행. 기준치는 팀 글 실측(공백 제외 약 4,500~5,900자, 소제목 8~9개). 조문·판례 번호는 확인된 목록과 자동 대조. 팀 공용 원고함으로 중복 주제를 막음.
- 넣지 않은 것: 키워드 검색량 조회(검색광고 API 키 필요), AI 생성 감지(판정 신뢰도가 낮음), AI 이미지, 유튜브 대본
