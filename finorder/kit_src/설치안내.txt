금융거래정보 제출명령 작성기 설치 안내

준비물
- Claude 유료 요금제(Pro 이상) 계정
- Claude 데스크톱 앱(Code 탭 사용) 또는 Claude Code
- 이 폴더(finorder-kit) 전체. 별도 커넥터는 필요 없습니다.


1단계. 설치 (Claude Code에서 1회, 약 3분)

1) Claude 데스크톱 앱의 Code 탭(또는 Claude Code)을 열고 작업 폴더로 이 finorder-kit 폴더를 선택합니다.
2) 입력창에 아래 한 줄을 입력합니다.

   신청서 작성기 설치해줘

3) 게시 허용을 묻는 창이 뜨면 허용합니다.
4) 마지막에 나오는 작성기 주소를 즐겨찾기에 추가합니다.

이미 설치한 적이 있으면 같은 말을 하면 새 버전으로 바꿔 줍니다. 주소는 그대로입니다.


2단계. 설치 확인 (웹에서 1회)

1) 즐겨찾기한 주소를 엽니다. 이제 Claude Code는 필요 없습니다.
2) 가상 이름(예: 홍길동)으로 사건 정보, 대상기관 1곳, 명의인, 거래기간을 채웁니다.
3) 'DOCX로 저장'을 누르고 허용 창이 뜨면 허용해서 파일이 저장되는지 확인합니다.
   확인용 입력에는 실제 의뢰인 정보를 쓰지 않습니다.


3단계. 사용 (매번, 웹에서)

사용법은 사용설명서.docx를 봅니다. 요약은 다음과 같습니다.
- 사건 정보, 대상기관, 명의인, 거래기간, 사용목적을 위에서 아래로 입력합니다.
- 오른쪽 미리보기에서 문안을 확인하고, 항목별 복사로 전자소송에 옮기거나 DOCX로 저장합니다.
- 보험사를 선택하면 5. 문안이 보험사용으로 바뀝니다. 보험 기준일을 입력합니다.


참고
- 작성기는 본인만 쓰는 개인 도구입니다. 공개 링크로 공유하지 않습니다.
- 이름, 주민등록번호, 사건번호는 어디에도 저장되지 않습니다. 새로고침하면 입력이 지워집니다.
- 기관 주소는 2026. 10. 2. 기준 제공 목록입니다. 제출 전 확인이 필요한 곳은 주소 수정으로 고칠 수 있습니다.
- 문제가 있으면 관리자(사무장)에게 문의합니다.
