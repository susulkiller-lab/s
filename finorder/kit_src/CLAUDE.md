# 신청서 작성기 설치 키트

이 폴더는 금융거래정보 제출명령 신청서 작성기를 직원 본인의 claude.ai 계정에 설치하는 키트다. 사용자가 "신청서 작성기 설치해줘", "설치해줘", "작성기 만들어줘"라고 하면 아래 순서를 그대로 수행한다. 사용자는 개발자가 아니므로 결론부터 짧게 경어체로 안내하고, 기술 용어는 쓰지 않는다. 마크다운 강조는 쓰지 않는다.

## 1. 준비 확인
- Artifact 도구를 쓸 수 있는지 확인한다. 쓸 수 없으면 게시하지 말고 다음을 안내한 뒤 멈춘다.
  "Claude 데스크톱 앱의 Code 탭(또는 최신 Claude Code)에서 이 폴더를 열고 다시 '설치해줘'라고 말씀해 주십시오."
- 이 작성기는 별도 커넥터가 필요 없다. 커넥터 확인은 하지 않는다.

## 2. 이미 설치했는지 확인
- Artifact 도구의 list(scope mine)로 내 아티팩트 중 제목이 '금융거래정보 제출명령 작성기'인 것이 있는지 확인한다.
- 있으면 사용자에게 "이미 설치되어 있습니다. 새 버전으로 바꿀까요? 주소는 그대로 유지됩니다."라고 묻는다. 동의하면 그 주소를 read로 먼저 읽은 뒤, 3단계의 게시를 url 지정으로 수행한다(주소 유지). 동의하지 않으면 멈춘다.
- 없으면 3단계를 새 게시로 수행한다.

## 3. 게시
Artifact 도구로 이 폴더의 finorder.html을 게시한다. 파일 내용은 수정하지 않는다. 게시 전에 파일 전체를 읽어 확인한다(약 5천 줄이고 줄마다 짧다).
- icon: form
- description: 사건 정보와 대상기관·명의인·거래기간·사용목적을 입력해 금융거래정보 제출명령 신청서(은행·금융기관용, 보험사용) 문안을 만들고 DOCX로 저장합니다.
- capabilities(아래 JSON 그대로):
  {"sample": {}, "db": {}, "user": {}, "downloads": true}
- 게시가 capabilities 때문에 거절되면 거절 사유를 사용자에게 그대로 전하고 멈춘다. capabilities를 빼고 게시하지 않는다(빼면 DOCX 저장, 기관 추가 저장, 사용목적 다듬기가 동작하지 않는다).
- 이미 이 대화에서 게시한 적이 있으면 같은 파일 경로로 다시 게시해 주소를 유지한다.
- 게시 뒤 별도의 기능 시험은 하지 않는다. 제작자가 시험을 마친 완성본이다.

## 4. 안내
게시가 끝나면 사용자에게 다음만 알린다.
1. 작성기 주소(즐겨찾기 권장). 앞으로는 Claude Code 없이 웹에서 이 주소로 쓴다.
2. 처음 'DOCX로 저장'이나 '다듬기'를 누를 때 허용 창이 뜨면 허용한다.
3. 설치 확인: 가상 이름(예: 홍길동)으로 필수 항목을 채우고 'DOCX로 저장'을 한 번 눌러 파일이 저장되는지 확인한다. 이 확인용 입력에는 실제 의뢰인 정보를 쓰지 않는다.
4. 사용법은 사용설명서.docx에 있다.

## 금지
- finorder.html을 고치거나 다시 쓰지 않는다. 문제가 있으면 사용자에게 관리자(사무장)에게 문의하라고 안내한다.
- source 폴더는 관리자용 원본이다. 설치에는 쓰지 않고 열어서 고치지도 않는다.
- 작성기를 공개 링크로 공유하라고 권하지 않는다. 의뢰인 이름과 주민등록번호를 입력하는 도구다.
- 사용자에게 의뢰인의 이름, 주민등록번호, 사건번호를 묻거나 파일에 적지 않는다.
