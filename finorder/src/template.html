기관 주소 최신화

이 화면에서는 인터넷 검색을 할 수 없습니다. 관리자가 Claude Code 세션에서 '금융기관 주소 최신화'를 요청하면 데이터 파일과 이 화면을 함께 갱신합니다. 그 사이 급히 바꿔야 하면 아래 순서로 직접 갱신할 수 있습니다.

  1. 요청문 복사 현재 기관 목록과 검증 규칙(독립 출처 2곳, 출처 주소 필수, 확인 못 하면 비움)이 담긴 요청문을 복사합니다.
  2. 웹 검색이 되는 Claude에 붙여 넣기 Claude Code 세션이나 웹 검색을 켠 대화에 요청문을 붙여 넣고, 돌려받은 JSON을 복사합니다.
  3. 결과 붙여넣기
  4. 비교 후 적용

목록에 없는 기관 추가

추가한 기관은 '추가' 표시와 함께 목록에 남아 다음에도 쓸 수 있습니다. 주소는 공식 자료로 확인한 값을 넣어 주십시오. 우편번호는 쓰지 않습니다.

보험사로 분류하면 보험사용 신청서(5. 문안이 다름)에 들어갑니다.

문서에 들어갈 순서

0곳 선택

    선택 세트

    자주 쓰는 기관 조합을 이름으로 저장해 두고 불러옵니다.
    2

    명의인

    계좌를 조회할 사람입니다. 여러 명이면 추가합니다.

    이름과 주민등록번호는 저장되지 않고 이 화면에서만 쓰입니다. Claude 호출에도 보내지 않습니다.

    번호는 숫자만 입력하면 하이픈이 자동으로 들어갑니다. 13자리는 주민등록번호 또는 법인등록번호, 10자리는 사업자등록번호입니다. 지위는 4. 사용목적의 대상 표기에 쓰입니다.

    3

    거래기간

    요구할 거래내역의 시작일과 종료일입니다.

    빠른 입력

    두 날짜를 모두 넣으면 문서에 '2023. 9. 1.부터 2026. 9. 1.까지' 형식으로 들어갑니다. 직접 입력은 점, 하이픈, 슬래시, 공백으로 구분해도 됩니다.

    4

    사용목적

    법원에 밝히는 사용목적 문장입니다.

    고정 문구

    원고 명의의 재산을 확인하여 재산분할 대상에 포함시키기 위함입니다.

    대상 표기는 2. 명의인의 지위에 맞춰 자동으로 바뀝니다.

    초안과 사건명만 Claude에 보냅니다. 이름, 번호, 사건번호는 보내지 않습니다.
    5

    보험 기준일

    보험사용 5.의 '○○ 기준', '○○ 이후', '○○ 이전'에 들어가는 날짜입니다. 문서에는 '2026. 3. 20.' 형식으로 쓰입니다.

    5

    요구하는 거래정보 문구

    은행·금융기관용 5.가 첫 문장의 '귀 ○○에'에 쓰입니다(보험사용은 항상 '귀 회사에'). 자동은 선택한 기관이 모두 은행류이면 '귀 은행', 하나라도 아니면 '귀 기관'입니다.

    사건, 명의인, 기간, 사용목적 입력을 모두 지웁니다. 기관 목록과 저장한 세트는 그대로 둡니다.

    신청서 미리보기

    소제목 옆 복사 버튼은 전자소송 입력용입니다.
    만들 신청서

    은행류와 보험사는 5. 요구하는 거래정보 문안이 달라 신청서를 따로 저장합니다. 고른 종류의 기관만 1.에 들어갑니다.
