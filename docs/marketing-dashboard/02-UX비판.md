총평: 원고실 재사용, 메신저 보고 붙여넣기, 분수와 %를 같은 단위로 맞춘 큰 방향은 맞습니다.

## 2. 초안에서 지켜야 할 좋은 결정

- 원고실과 같은 로그인 경로를 쓰되 개인 설치 키트와 섞이지 않게 별도 페이지로 둔 것, 메신저 보고를 입력으로 삼는 방향
- 분수와 %를 같은 단위로 세고, 내림 표시로 다 끝나야 100%, 초과분은 %에 섞지 않는 것
- 반복 업무를 주마다 새로 시작해 미달이 눈덩이처럼 쌓이지 않게 한 것
- 즉시 반영, 5초 되돌리기, 저장 실패 시 숫자 원복과 안내
- 색과 글자 병기, 쉬운 말 용어표, 카드당 행동 하나, '오늘은 쉬는 날'
- 문의에 이름·연락처를 받지 않고 번호 형태 입력을 막는 것
- 회의 업무와 지시를 한 종류로 묶고, 목표 이력으로 지난 숫자를 고정한 것
- 측정 가능한 성공 기준, 메신저 병행 파일럿, 소리·sample·room을 미룬 것
