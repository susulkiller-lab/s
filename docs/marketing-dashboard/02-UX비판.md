## 2. 초안에서 지켜야 할 좋은 결정

- 새 계정·새 앱 없이 원고실과 같은 로그인 경로를 쓰고, 개인 설치 키트와 섞이지 않게 별도 페이지로 둔 것
- 지금 쓰는 메신저 보고를 그대로 입력으로 삼는 방향(이중 입력을 줄이려는 출발점)
- 분수와 %를 같은 단위로 세고, 내림 표시로 다 끝났을 때만 100%가 되며, 초과분을 %에 섞지 않은 것
- 반복 업무를 주 단위로 새로 시작해 미달이 눈덩이처럼 쌓이지 않게 한 것(미달은 기록에 남김)
- 서버 응답을 기다리지 않는 즉시 반영, 5초 되돌리기, 저장 실패 시 원래 숫자로 돌리고 알리는 것
- 색과 글자를 함께 쓰는 규칙, 쉬운 말 용어표, 카드당 행동 하나, 휴무일의 '오늘은 쉬는 날'
- 문의에 이름·연락처를 받지 않고 번호 형태 입력을 막는 것
- 회의 업무와 지시를 한 종류로 묶은 것, 목표 이력으로 지난 기간 숫자를 고정한 것
- 측정 가능한 성공 기준(1분 테스트, 하루 2분 입력)과 메신저 병행 파일럿
- 움직임 줄이기 설정 존중, 소리 제외, 내보내기 라이브러리 지연 로드, sample·room·워드 차트를 미룬 것
