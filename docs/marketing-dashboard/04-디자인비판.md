총평: 기능 설계는 탄탄하지만 화면은 '원고실 토큰 재사용'에 머물러 토스식 산뜻함이 아직 규격으로 옮겨지지 않았습니다.

아래 규격대로 고치면 기능을 늘리지 않고 '1분 이해'와 '체크 쾌감'을 함께 맞출 수 있으며, 계기판 느낌은 첫 화면 게이지 하나로만 들이고 테마는 하나로 둡니다.

### 2.3 간격, 반경, 카드, 조작부

- 간격은 4의 배수(4, 8, 12, 16, 20, 24, 32)만 씁니다. 화면 좌우 여백 16(데스크톱 24), 카드 안 여백 20(화면 폭 374 이하 16), 카드 사이 12, 묶음 사이 24입니다.
- 반경: 카드 16, 버튼·입력칸 12, 바텀시트 위쪽 20, 배지 999.
- 그림자와 카드 테두리는 없고 면 색 차이로 구분합니다. 떠 있는 바텀시트와 토스트만 `0 4px 16px rgba(0,0,0,.12)`를 쓰고, 다크에서는 그림자 대신 --surface-2 면을 씁니다.
- 행: 최소 높이 60(보조줄 있으면 68), 구분선 없음, 제목은 한 줄 말줄임입니다. 왼쪽은 제목(row)과 보조줄(caption), 오른쪽은 조작부입니다.
- 체크 원(목표 3 이하): 보이는 지름 28, 누름 영역 44×44(이웃 원과 겹치지 않음). 빈 원은 2px --control 테두리, 찬 원은 --accent 면에 --on-accent 체크(선 2.5)입니다. 어느 원을 눌러도 다음 빈 원이 찹니다. 찬 원을 누르면 아무 일도 없어 연타 이중 기록이 생기지 않습니다. 되돌리기는 토스트와 상세 시트에서만 합니다.
- 목표 4 이상: 분수 '3/14'(16/700)와 '+1' 버튼(44×44, --surface-2 면)을 두고, 분수 아래 높이 4 막대를 붙입니다. 초과분은 보조줄에 '+1 더 함'으로 적습니다.
- 막대(이번 주, 업무별 달성률): 높이 8(표 안 6), 반경 4, 채움은 `transform: scaleX`로 움직입니다(width 애니메이션 금지).
- 버튼: 주 버튼 높이 52, --accent-strong 면. 보조 버튼 높이 52, --surface-2 면에 --ink 글자.
- 탭 줄: 높이 56에 safe-area를 더하고 탭 4개를 균등 배치합니다. 아이콘 24와 글자 12를 쓰며, 선택은 색과 함께 아이콘 채움과 굵기로 표시합니다.
- 토스트: 탭 줄 위 12px, 높이 48, --ink 면에 흰 글자(16.56:1), 5초 유지. 초점 고리는 2px --focus, 간격 2px입니다.

### 2.4 체크 연출 타이밍

화면 반응은 누른 뒤 한 프레임(16ms) 안에 시작하고 서버 응답을 기다리지 않습니다. 움직이는 속성은 transform, opacity, stroke-dashoffset만 씁니다.

| 순간 | 연출 | 길이(ms) | 곡선 |
|---|---|---|---|
| 손가락 닿음 | 원이 0.9배로 줄어듦 | 80 | ease-out |
| 뗌(기록) | 원 채움, 체크 선 그리기, 0.9→1.08→1 튐(동시 시작) | 150, 220, 240 | 튐은 cubic-bezier(.34,1.56,.64,1) |
| 같은 순간 | 게이지·이번 주 막대 차오름 | 600 | cubic-bezier(.22,1,.36,1) |
| 같은 순간 | 큰 숫자 올림(count-up) | 400 | ease-out |
| 같은 순간 | 진동(지원 기기만) | 10 | - |
| 업무 하나 목표 도달 | 제목이 흐려지고 보조줄 '끝 · 14:20'이 나타남. 행은 움직이지 않음 | 200(220 뒤 시작) | ease-out |
| 되돌리기 토스트 | 들어옴, 나감, 유지 | 200, 140, 5,000 | ease-out, ease-in |
| 오늘 100% | 게이지가 다 찬 뒤 숫자 자리가 체크 아이콘으로 바뀜(0.6→1), 게이지 끝에서 점 12개 퍼짐, 문구 교체 | 280, 700, 200. 총 1,300 이내 | 튐 곡선 |
| 붙여넣기 반영 | 행마다 위 연출, 행 사이 60 시차, 게이지·숫자는 최종값으로 한 번 | 총 1,000 이내 | 위와 같음 |
| 남의 체크(실시간) | 숫자 즉시 교체, 그 행 바탕이 --accent-soft에서 투명으로. 순서 불변 | 1,000 | linear |
| 첫 로딩 | 회색 뼈대 다음 최종값 정지. 0에서 차오르기 금지 | - | - |
| 저장 실패 | 원을 비우고 보조줄에 '저장하지 못했어요. 다시 눌러 주세요'(--late) | 150 | ease-out |

### 2.5 상태 표기 규칙

| 상태 | 색 | 아이콘 | 글자 예 | 자리 |
|---|---|---|---|---|
| 끝 | --accent | 찬 체크 원 | '끝 · 14:20 이OO' | 오른쪽 원, 보조줄 |
| 남음 | 없음 | 빈 원 | 배지 없음(기본 상태) | 오른쪽 원 |
| 밀림 | --late, --late-soft | 느낌표 원 | '밀림 · 월요일분', 지시는 'D+3' | 보조줄 배지 |
| 오래 못 함 | --stale, --stale-soft | 시계 | '오래 못 함 · 9일째' | 보조줄 배지 |
| 건너뜀·쉬는 날 | --ink-3 | 빼기 원 | '건너뜀 · 외근', '오늘은 쉬는 날' | 보조줄 |
| 늦게 기록 | --ink-3 | 없음 | '늦게 기록' | 상세 시트, 엑셀만 |

- 색은 배지와 원에만 쓰고 카드 면을 칠하지 않습니다. 한 행에 배지는 1개만 답니다(밀림, 오래 못 함, 건너뜀 순).
- 밀린 일이 0이면 빨강 '0' 대신 회색 체크 아이콘과 '밀린 일 없음'을 보입니다.
- 아이콘은 인라인 SVG(24 격자, 선 2px)이고 이모지는 쓰지 않습니다. 아이콘은 aria-hidden으로 두고 뜻은 글자가 전합니다.

### 2.6 집계 화면(문의·성과) 형식

| 정보 | 형식 | 비고 |
|---|---|---|
| 문의 수, 리뷰 요청률, 다시 연락 필요 | 숫자 타일 3개(stat) | 증감은 '지난주보다 3건 늘었어요'처럼 글자와 ▲▼로 적고 색은 넣지 않음 |
| 유형별(전화·방문·예약) | 한 줄 숫자 3개 | 값 3개에 차트는 필요 없음 |
| 경로별, 분야별 | 가로 막대, --data 단색, 많은 순, 막대 끝에 숫자 | 0건은 접음. 숫자가 적혀 있으므로 툴팁 없음 |
| 경로×유형 교차 | 표(0은 '-') | 쌓은 막대 대신 표 |
| 검색어 상위 10 | 순위 표 | 워드클라우드 금지 |
| 업무별 달성률(성과) | 표 안에 너비 64 막대(--accent)와 % 글자, 낮은 순 | 초록은 목표 대비 진척, --data는 건수로 구분 |

- 게이지는 첫 화면 1개뿐이고 집계 화면에는 원, 도넛, 게이지, 3D, 그라데이션, 이중 축, 막대마다 다른 색을 쓰지 않습니다. 차트 라이브러리 없이 HTML 막대로 충분합니다.

### 3.1 비교

### 3.2 혼합안 규격(오늘 게이지)

- 자리: 첫 화면 히어로 카드 가운데에 1개만 둡니다. 다른 화면에는 게이지를 두지 않습니다.
- 각도: 240° 호입니다. 8시 방향(0%)에서 시계 방향으로 4시 방향(100%)까지 갑니다. 아래 120° 빈 틈에 '10개 중 6개 끝냈어요'를 넣어 숫자와 설명을 한 덩어리로 묶습니다.
- 크기: 지름 모바일 180, 데스크톱 240. 호 두께 14(데스크톱 16), 끝은 둥글게 합니다.
- 눈금: 0·25·50·75·100% 5개만, 호 바깥 4px에 길이 6, 두께 2, --control 색. 숫자 라벨은 없습니다(가운데 숫자가 답입니다).
- 색 구간: 두지 않습니다. 채움은 --accent 단색, 빈 부분은 --track입니다. 낮은 구간을 빨강으로 칠하면 0%가 정상인 아침마다 경고처럼 보이고 '빨강=밀림' 규칙과 충돌합니다.
- 바늘 대신 채움: 바늘은 눈금과 맞대어야 읽히고 '얼마나 찼는지'가 덜 보이며 회전축 구현이 늘어납니다. 채움의 둥근 끝이 바늘 역할을 합니다.
- 가운데: 숫자 40/700(데스크톱 48)과 '%' 22/700, 위에 '우리 팀 오늘'(13)을 둡니다. 100%면 숫자 자리에 체크 아이콘 44와 '다 끝냈어요'가 들어갑니다.
- 모션: 체크 순간 이전 값에서 새 값으로 600ms 차오르고(cubic-bezier(.22,1,.36,1)), 숫자는 400ms 동안 올라갑니다. 시동 때 바늘이 한 바퀴 도는 식의 첫 로딩 쓸기는 하지 않습니다(지적 14).
- 경고등: 계기판 요소 중 경고등 문법만 '밀린 일' 칸에 빌려 씁니다. 1 이상이면 --late 느낌표와 숫자를, 0이면 회색 '밀린 일 없음'(꺼진 경고등)을 보입니다.
- 구현: SVG 하나에 같은 호 경로 2개(트랙, 채움)와 짧은 선 5개를 둡니다. 채움 경로에 pathLength=100을 주고 stroke-dasharray를 '현재% 100'으로 바꾸면 됩니다. SVG에 role=img와 aria-label('우리 팀 오늘 10개 중 6개 끝, 60%')을 붙입니다.
- 금지: 발광, 그라데이션 호, 그림자, 금속 질감, 7세그먼트 디지털 글꼴.

### 3.3 회의용 '계기판 모드' 판단

- 별도 테마로는 MVP에도 2단계에도 만들지 않습니다. 2.1절 다크 토큰이 있어 운영체제 다크 설정이나 data-theme="dark"만으로 같은 화면이 어두운 계기판처럼 보입니다. 테마를 한 벌 더 두면 색 검증과 유지보수가 두 배가 됩니다.
- 2단계 후보: 파일럿 중 회의에서 화면을 띄우는 일이 주 1회 이상이면 '회의 보기' 한 가지만 검토합니다. 데스크톱 배치에 다크 토큰 강제, 글자 1.5배, 입력 버튼 숨김만 적용하고 새 색이나 새 구성 요소는 만들지 않습니다.
- 결론: 테마는 하나(같은 토큰의 라이트·다크 자동)로 둡니다. 계기판 느낌은 첫 화면 게이지 하나와 밀린 일 경고등으로만 들입니다.
