총평: 기능 설계는 탄탄하지만 화면은 원고실 토큰을 옮긴 수준이라 토스식 산뜻함이 아직 규격으로 내려오지 않았습니다.
치명 문제는 둘입니다. '60%'가 문장 끝에 묻혀 위계가 없고, 끝난 카드가 곧바로 아래로 사라져 쾌감 대신 오터치를 부릅니다.
아래 규격대로 고치면 기능 추가 없이 1분 이해와 체크 쾌감을 맞출 수 있습니다. 계기판 느낌은 첫 화면 게이지 하나로만 들이고 테마는 하나로 둡니다.

### 2.2 글꼴과 크기

- 불러오기 `https://fonts.googleapis.com/css2?family=Inter:wght@400..700&family=Noto+Sans+KR:wght@400;500;700&display=swap`, 순서 `"Inter","Noto Sans KR","Apple SD Gothic Neo","Malgun Gothic",system-ui,sans-serif`. 숫자·영문은 Inter, 한글은 Noto Sans KR로 그려져 Pretendard(Inter+본고딕 계열)에 가장 가깝습니다. 명조와 Plex Mono는 쓰지 않습니다.
- 바뀌는 숫자(게이지 %, 분수, 개수, 표)는 `font-variant-numeric: tabular-nums`. Inter 파일의 tnum 지원을 확인했고, 올라가는 동안 흔들리지 않게 하려는 의도적 예외입니다(Plex KR·Noto Sans KR 파일은 숫자가 원래 고정폭).
- 크기(px/굵기): 게이지 숫자 40/700(데스크톱 48, 자간 -0.02em), 보조 숫자 24/700, 날짜 20/700, 묶음 제목·주 버튼 17/700, 업무 이름 16/500, 본문 15/400(행간 1.5), 보조줄 13/400, 배지 12/500. 배지 밖에서 13px 미만 금지.

### 2.3 간격, 반경, 카드, 조작부

- 간격은 4의 배수. 화면 좌우 16(데스크톱 24), 카드 안 20(폭 374 이하 16), 카드 사이 12, 묶음 사이 24. 반경은 카드 16, 버튼·입력칸 12, 바텀시트 위 20, 배지 999. 카드 그림자·테두리 없이 면 색으로 구분하고, 바텀시트·토스트만 `0 4px 16px rgba(0,0,0,.12)`(다크는 --surface-2 면).
- 행: 최소 높이 60(보조줄 있으면 68), 구분선 없음, 제목 한 줄 말줄임. 왼쪽 제목과 보조줄, 오른쪽 조작부.
- 체크 원(목표 3 이하): 보이는 지름 28, 누름 영역 44×44(이웃과 겹치지 않음). 빈 원은 2px --control 테두리, 찬 원은 --accent 면에 --on-accent(흰색, 다크 #08130C) 체크. 어느 원을 눌러도 다음 빈 원이 차고, 찬 원은 반응하지 않아 연타 이중 기록이 없습니다. 되돌리기는 토스트와 상세 시트로만. 목표 4 이상은 분수 '3/14'(16/700)와 '+1' 버튼(44×44), 초과분은 보조줄 '+1 더 함'.
- 막대 높이 8(표 안 6)·반경 4·`transform: scaleX`로 이동. 주·보조 버튼 높이 52, 탭 줄 56+safe-area(선택은 색과 아이콘 채움·굵기 병기), 토스트 높이 48·5초, 초점 고리 2px.

### 2.4 체크 연출 타이밍

누른 뒤 한 프레임(16ms) 안에 반응하고 서버 응답을 기다리지 않습니다. 움직이는 속성은 transform, opacity, stroke-dashoffset만 씁니다.

|---|---------|---|
| 손가락 닿음 | 원 0.9배 | 80 |
| 뗌(기록) | 원 채움, 체크 선 그리기, 0.9→1.08→1 튐(cubic-bezier(.34,1.56,.64,1)), 진동 10ms | 150 / 220 / 240 |
| 같은 순간 | 게이지·이번 주 막대 차오름(cubic-bezier(.22,1,.36,1)), 숫자 올림 | 600 / 400 |
| 업무 목표 도달 | 제목 흐려짐, 보조줄 '끝 · 14:20' 나타남, 행은 그대로 | 200 |
| 되돌리기 토스트 | 들어옴 / 나감 / 유지 | 200 / 140 / 5,000 |

### 2.5 상태 표기 규칙

| 상태 | 색 | 아이콘 | 글자(보조줄 배지) |
|---|---|---|------|
| 끝 | --accent | 찬 체크 원 | '끝 · 14:20 이OO' |
| 남음 | 없음 | 빈 원 | 배지 없음(기본 상태) |

### 2.6 집계 화면(문의·성과) 형식

- 숫자 타일: 문의 수, 리뷰 요청률, 다시 연락 필요. 증감은 '지난주보다 3건 늘었어요'처럼 글자와 ▲▼로만 적고 색은 넣지 않습니다. 유형별 3개(전화·방문·예약)도 한 줄 숫자로 충분합니다.
- 가로 막대(경로별, 분야별): --data 단색, 많은 순, 막대 끝에 숫자, 0건은 접고 툴팁은 두지 않습니다. 표: 경로×유형 교차(0은 '-'), 검색어 상위 10, 성과의 업무별 달성률(표 안 너비 64 --accent 막대와 %, 낮은 순).
- 금지: 원, 도넛, 집계용 게이지, 3D, 그라데이션, 이중 축, 막대마다 다른 색, 워드클라우드. 차트 라이브러리 없이 HTML 막대로 만듭니다.

### 3.2 혼합안 규격(오늘 게이지)

- 자리와 각도: 첫 화면 히어로 카드에 1개. 240° 호로 8시 방향 0%에서 시계 방향 4시 방향 100%까지. 아래 120° 틈에 '10개 중 6개 끝냈어요'를 넣어 숫자와 설명을 한 덩어리로 묶습니다.
- 크기: 지름 180(데스크톱 240), 호 두께 14(16), 둥근 끝. 가운데 숫자 40/700과 '%' 22/700, 위에 '우리 팀 오늘' 13.
- 눈금: 0·25·50·75·100% 5개만, 호 바깥 4px에 길이 6·두께 2·--control. 숫자 라벨 없음.
- 색 구간 없음: 채움은 --accent 단색, 빈 곳은 --track. 낮은 구간을 빨강으로 두면 0%가 정상인 아침마다 경고처럼 보이고 '빨강=밀림' 규칙과 충돌합니다.
- 바늘 대신 채움: 바늘은 눈금과 맞대어야 읽히고 회전축 구현이 늘어납니다. 채움의 둥근 끝이 바늘 역할을 합니다.
- 모션: 체크 때 이전 값에서 새 값으로 600ms 차오름, 숫자 400ms. 100%면 숫자 자리에 체크 아이콘 44와 '다 끝냈어요'(2.4절). 시동식 첫 로딩 쓸기는 하지 않습니다.
- 경고등: 계기판 요소 중 경고등 문법만 '밀린 일' 칸에 빌립니다. 1 이상이면 --late 느낌표와 숫자, 0이면 회색 '밀린 일 없음'(꺼진 경고등).
- 구현: SVG 하나에 같은 호 경로 2개(트랙, 채움)와 짧은 선 5개. 채움 경로에 pathLength=100을 주고 stroke-dasharray만 바꿉니다. role=img와 aria-label('우리 팀 오늘 10개 중 6개 끝, 60%')을 붙입니다. 발광·그라데이션·그림자·7세그먼트 글꼴은 금지합니다.

### 3.3 회의용 '계기판 모드' 판단

- 별도 테마는 MVP에도 2단계에도 만들지 않습니다. 2.1절 다크 토큰만으로 운영체제 다크 설정이나 data-theme="dark"에서 같은 화면이 어두운 계기판처럼 보이며, 테마를 한 벌 더 두면 색 검증과 유지보수가 두 배가 됩니다.
- 2단계 후보: 파일럿 중 회의에 화면을 띄우는 일이 주 1회 이상이면 '회의 보기' 한 가지만 검토합니다. 데스크톱 배치, 다크 강제, 글자 1.5배, 입력 버튼 숨김만 적용하고 새 색·새 구성 요소는 만들지 않습니다.
- 결론: 테마는 하나(같은 토큰의 라이트·다크 자동)이고, 계기판 느낌은 오늘 게이지와 밀린 일 경고등으로만 들입니다.
