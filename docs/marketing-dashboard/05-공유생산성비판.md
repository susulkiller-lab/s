## 3. 공유 범위 매트릭스

'열람 / 입력' 순서이며 O 가능, X 불가, △ 조건부입니다. 0주 실측에서 팀원·상담 직원이 편집자로 확인되면 이들 칸의 제한은 DB가 아니라 화면 수준입니다.

| 데이터 | 팀원 | 사무장 | 대표·변호사 | 상담 직원 | 외부 |
|---|---|---|---|---|---|
| 업무 체크 | O / O(본인 몫) | O / O(대리 포함) | △(뷰어 초대 시) / X | X / X | X / X |
| 개인 성과 | △(본인 것만) / 자동 | O / 자동 | X / X | X / X | X / X |
| 팀 성과 | O / X | O / 메모 | O(대표 보고용 docx) / X | △(단체방 요약) / X | X / X |
| 문의 상세 | O / O | O / O, 원장 내보내기 | X(사무장 경유) / △(직접 받은 문의) | △(계정 있을 때) / O(직접 또는 4칸 경유) | X / X |
| 문의 집계 | O / X | O / X | O(월간 docx) / X | O(월 1회 요약) / X | X / X |

- 외부(대행사·외주 작가 등)는 초안 3절대로 현재 없다고 보고, 생기면 따로 정하며 공개 링크 금지는 유지합니다.
