# 팀 문체 규칙

팀 글 3편(2026-09-28 제공) 실측과 legal-blog-writer 기준을 합친 규칙이다. 실측 절이 공통 절보다 우선한다.

## 공통(임시)
- 경어체(-습니다/-입니다) 기본. 핵심 강조에서만 짧은 단문 허용.
- 법률 용어는 처음 나올 때 괄호로 일상어를 붙인다. 예: 채무불이행(약속한 돈을 갚지 않는 것).
- 번역투·일본어투 배제: "~에 있어서" → "~에서", "~하는 것이다" → "~합니다".
- 낚시성 수식어("충격적인", "반드시 알아야 할") 금지. 공포 마케팅 금지.
- 정보를 아끼지 않는다. "자세한 건 상담받으세요"로 끊지 않고 기한·서류·절차를 구체적으로 적는다.
- CTA는 절제한다. 예: "비슷한 상황이라면 자료를 정리해 상담을 받아 보시길 권합니다."

- 법령 해석 금지: 법령·판례의 의미는 조문 문언이나 확인된 판례의 판시 내용 그대로만 쓴다. '해석되는 경우가 많다', '해석될 수 있다', '일반적으로 논의된다', '알려져 있다', '설명된다', '실무상 ~하는 경우가 많다', '~라는 견해·반론도 있다', '경향이 있다', '볼 여지가 있다'처럼 근거를 댈 수 없는 해석·경향·학설 서술은 쓰지 않는다. 근거가 없으면 그 문장을 뺀다.

## 채널별 각도(임시)
- 네이버 블로그: 사례 도입 → 문제 정의 → 법률 근거 → 사례 적용 → 실무 절차 → 자주 묻는 질문 → 마무리. 모바일 가독성 우선, 3~4문장마다 문단 분리.
- 로톡: 질문에 먼저 답하는 결론 선행형. 절차·비용·기간 정보 비중을 높인다.
- 티스토리: 판례·법리 해설형. 구글 검색 유입을 고려해 소제목을 정보 요약형으로 쓰고 정의·요건을 명확히 정리한다.

## 코퍼스 실측(2026-09-28, 팀 글 3편, 채널 미상)
- 분량·구조: 공백 제외 4,472~5,850자, 소제목 8~9개, 서술 문장 평균 47~65자, 문단은 1~2문장. 수치는 corpus/REPORT.md 참조.
- 제목: 질문형 또는 상황 제시 + 핵심 정리어 + 꼬리표 "[창원 ○○ 변호사]". 49~60자. 대표 키워드가 제목 중간에 오는 경우가 많다.
- 도입 방식: 의뢰인 질문 2개를 “ ”로 인용해 한 줄씩 → 상황 설명 → "단순히 ~만으로 ~인정되는 것은 아닙니다" 식 균형 문장 → "그렇다면 ~ 살펴보겠습니다" 또는 "결론부터 말하면"으로 전환.
- 소제목 말투: 질문형("~될 수 있을까?", "~해야 할까요?")과 서술형("~는 다릅니다", "~부터 확인해야 합니다") 혼용. 번호 없음.
- 본문 구성: 판단 기준(조문 "~라고 규정하고 있습니다", 대법원 "~라고 보고 있습니다") → 사례 대비 → 준비 자료·증거(①②③ 또는 표를 행 단위로) → "○○, 자주 묻는 질문" Q1~Q5·Q7 → 핵심 명제형 마무리 소제목과 요약.
- 마무리·CTA 문구: "진앤솔 법률사무소는 ~ 자료를 검토하여 ~을 살펴보고 있습니다." + "~ 상황이라면 ~ 구체적으로 살펴볼 필요가 있습니다." 그 뒤 사무소 소개 서명 문단(고정 문구, 생성 대상 아님).
- 자주 쓰는 연결어·종결어미: 다만(4~7회), 따라서(5~8회), 반면, 특히, 결국 / "~할 수 있습니다"(17~29회), "~것은 아닙니다"(6~9회), "~확인해야 합니다", "~살펴볼 필요가 있습니다".
- 쓰지 않는 표현: 굵게·기울임 같은 강조, 이모지, 해시태그, 결과 보장·비교 표현.
- 주의: 판례를 사건번호 없이 "대법원은 ~ 보고 있습니다"로 서술하는 문장이 많다. 원고실은 확인된 판례가 없으면 이런 문장에 경고를 띄운다.
