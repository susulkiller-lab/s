진앤솔 원고실 설치 안내

준비물
- Claude 유료 요금제(Pro 이상) 계정
- Claude 데스크톱 앱(Code 탭 사용) 또는 Claude Code
- 이 폴더(wonkosil-kit) 전체


1단계. 법령mcp 커넥터 추가 (웹에서 1회, 약 1분)

1) 브라우저에서 claude.ai에 로그인합니다.
2) 설정 → 커넥터 → 사용자 지정 커넥터 추가를 누릅니다.
3) 이름: 법령mcp   (띄어쓰기 없이 정확히 이대로)
4) 주소: [관리자가 알려 준 주소를 여기에 붙여넣기]
5) 추가를 누르고, 연결 확인 창이 뜨면 허용합니다.

이름이 다르면 원고실이 법령 원문을 확인하지 못합니다.


2단계. 원고실 설치 (Claude Code에서 1회)

1) Claude 데스크톱 앱의 Code 탭(또는 Claude Code)을 열고 작업 폴더로 이 wonkosil-kit 폴더를 선택합니다.
2) 입력창에 아래 한 줄을 입력합니다.

   원고실 설치해줘

3) 게시 허용을 묻는 창이 뜨면 허용합니다.
4) 마지막에 나오는 원고실 주소를 즐겨찾기에 추가합니다.


3단계. 사용 (매번, 웹에서)

1) 즐겨찾기한 원고실 주소를 엽니다. Claude Code는 더 필요 없습니다.
2) 처음 생성하기를 누를 때 뜨는 허용 창 두 개(Claude 사용, 법령mcp 사용)를 허용합니다.
3) 상단에 '법령mcp 연결됨'이 보이면 준비 완료입니다.
4) 설정 탭에서 서명 문구를 한 번 붙여 두면 '서명 포함 복사'에 함께 붙습니다.


참고
- 원고실은 본인만 보는 개인 도구입니다. 원고함도 본인 원고만 쌓입니다.
- 글 생성은 본인 Claude 사용량으로 처리됩니다. 한 편에 5~9회 호출합니다.
- 게시 전에는 반드시 담당 변호사 검토를 받습니다.
