# 원고실 설치 키트

이 폴더는 진앤솔 법률사무소 마케팅팀원이 자기 claude.ai 계정에 '원고실'(법률 블로그 원고 작성 도구)을 설치하는 키트다. 사용자가 "원고실 설치해줘", "설치해줘", "원고실 만들어줘"라고 하면 아래 순서를 그대로 수행한다. 사용자는 개발자가 아니므로 결론부터 짧게 경어체로 안내하고, 기술 용어는 쓰지 않는다.

## 1. 법령mcp 커넥터 확인
- 커넥터 목록을 확인할 수 있으면(ListConnectors 등) 이름이 정확히 '법령mcp'인 커넥터가 연결되어 있는지 확인한다.
- 없거나 연결되지 않았으면 게시하지 말고 사용자에게 다음을 안내한 뒤 멈춘다.
  "claude.ai 웹 → 설정 → 커넥터 → 사용자 지정 커넥터 추가에서 이름은 '법령mcp'(띄어쓰기 없이), 주소는 설치안내.txt의 주소를 넣고 추가해 주십시오. 추가한 뒤 이 대화에서 다시 '설치해줘'라고 말씀해 주십시오."
- 커넥터 목록을 확인할 방법이 없으면 사용자에게 추가했는지 한 번 묻고, 추가했다고 하면 진행한다.
- 이름이 '법령mcp'와 다르면 원고실이 법령 원문 확인을 할 수 없다. 이름을 바꿔 다시 추가하도록 안내한다.

## 2. 원고실 게시
Artifact 도구로 이 폴더의 wonkosil.html을 게시한다. 파일 내용은 수정하지 않는다.
- icon: pen
- description: 법률 블로그 원고 작성·검수 도구
- capabilities(아래 JSON 그대로):
  {"sample": {}, "db": {"rules": [{"path": "", "read": "view", "write": "interact"}, {"path": "settings", "write": "admin"}]}, "user": {"scopes": ["profile"]}, "mcp": {"servers": [{"server": "법령mcp", "tools": ["search_law", "get_law_text", "search_decisions"]}]}}
- 게시가 법령mcp 때문에 거절되면(커넥터 없음 등) 1단계 안내로 돌아간다. 이때 mcp를 빼고 게시하지 않는다. 사용자가 "법령 확인 없이 설치"를 명시적으로 원할 때만 mcp 항목을 빼고 게시한다.
- 이미 이 대화에서 게시한 적이 있으면 같은 파일 경로로 다시 게시해 주소를 유지한다.

## 3. 안내
게시가 끝나면 사용자에게 다음만 알린다.
1. 원고실 주소(즐겨찾기 권장). 앞으로는 Claude Code 없이 웹에서 이 주소로 쓴다.
2. 처음 생성하기를 누르면 Claude 사용 허용과 법령mcp 사용 허용 창이 뜨니 허용한다.
3. 상단 상태 표시에 '법령mcp 연결됨'이 보이면 준비 완료다.
4. 설정 탭에서 서명 문구를 붙여 두면 '서명 포함 복사'에 쓰인다.

## 금지
- wonkosil.html을 고치거나 다시 쓰지 않는다. 문제가 있으면 사용자에게 관리자(마케팅 팀장)에게 문의하라고 안내한다.
- 원고실을 공개 링크로 공유하라고 권하지 않는다.
