# 위임계약서 작성기 설치 키트

이 폴더는 진앤솔 법률사무소 직원이 자기 claude.ai 계정에 '위임계약서 작성기'(형사, 민사·행정 사건위임계약서를 빈칸 입력만으로 워드 파일 A4 3장으로 만드는 도구)를 아티팩트로 설치하는 키트다. 사용자가 "위임계약서 설치해줘", "작성기 설치해줘", "설치해줘"라고 하면 아래 순서를 그대로 수행한다. 사용자는 개발자가 아니므로 결론부터 짧게 경어체로 안내하고, 기술 용어는 쓰지 않는다.

## 1. 게시
Artifact 도구로 이 폴더의 wiim.html을 게시한다. 파일 내용은 수정하지 않는다.
- wiim.html은 이미 첫 줄이 `<title>`로 시작하는 게시용 조각이다. doctype, html, head, body 태그를 덧붙이지 않는다.
- icon: file
- description: 형사, 민사·행정 사건위임계약서를 빈칸 입력으로 워드(A4 3장) 파일로 만드는 도구
- capabilities(아래 JSON 그대로): {"downloads": {}}
- 게시 도구가 capabilities나 디자인 관련 안내 스킬을 먼저 읽으라고 요구하면 읽되, 그 안내에 따라 wiim.html의 내용을 고치지는 않는다.
- 파일 저장 기능(downloads)이 요금제나 조직 설정 때문에 거절되면 기능을 빼고 게시하지 않는다. 사용자에게 "이 계정에서는 파일 저장 기능을 쓸 수 없어 설치할 수 없습니다. 관리자에게 문의해 주십시오."라고 안내하고 멈춘다.
- 이 대화에서 이미 게시한 적이 있으면 같은 파일 경로로 다시 게시해 주소를 유지한다.

## 2. 안내
게시가 끝나면 사용자에게 다음만 알린다.
1. 작성기 주소(즐겨찾기 권장). 앞으로는 Claude Code 없이 웹에서 이 주소로 쓴다.
2. 맨 위에서 형사 또는 민사·행정을 고르고 빈칸을 입력하면 오른쪽에 미리보기가 나오고, 아래 '워드 파일 저장'을 누르면 워드 파일이 저장된다. 처음 저장할 때 파일 저장 허용 창이 뜨면 허용한다.
3. 저장한 파일을 워드에서 열어 3쪽(계약서 2쪽, 동의서 1쪽)인지 확인한다.
4. 입력한 내용은 화면 안에서만 처리되고 서버에 저장되지 않는다.

## 금지
- wiim.html을 고치거나 다시 쓰지 않는다. 문제가 있으면 사용자에게 관리자에게 문의하라고 안내한다.
- 작성기를 공개 링크로 공유하라고 권하지 않는다. 공유가 필요하면 이메일 초대를 안내한다.
- 양식 문구에 법률 판단을 덧붙이거나 고치지 않는다. 양식 문구는 원본 사건위임계약서를 그대로 옮긴 것이다.
