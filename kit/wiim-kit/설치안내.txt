위임계약서 작성기 설치 안내

준비물
- Claude 유료 요금제(Pro 이상) 계정
- Claude 데스크톱 앱(Code 탭) 또는 Claude Code
- 이 폴더(wiim-kit) 전체 (zip으로 받았으면 먼저 압축을 풉니다)


1단계. 작성기 설치 (Claude Code에서 1회)

1) Claude 데스크톱 앱의 Code 탭(또는 Claude Code)을 열고 작업 폴더로 이 wiim-kit 폴더를 선택합니다.
2) 입력창에 아래 한 줄을 입력합니다.

   위임계약서 설치해줘

3) 게시 허용을 묻는 창이 뜨면 허용합니다.
4) 마지막에 나오는 작성기 주소를 즐겨찾기에 추가합니다.


2단계. 사용 (매번, 웹에서)

1) 즐겨찾기한 작성기 주소를 엽니다. Claude Code는 더 필요 없습니다.
2) 맨 위에서 형사 또는 민사·행정을 고릅니다.
3) 왼쪽 빈칸을 입력하면 오른쪽에 A4 미리보기가 바로 바뀝니다.
4) 아래 '워드 파일 저장'을 누릅니다. 처음 저장할 때 파일 저장 허용 창이 뜨면 허용합니다.
5) 저장한 파일을 워드에서 열어 3쪽(계약서 2쪽, 동의서 1쪽)인지 확인한 뒤 인쇄합니다.


입력 항목

- 위임인 성명: 상단 '위임인(갑) :' 줄에만 인쇄됩니다. 하단 서명란에는 이름을 넣지 않아 위임인이 자필로 씁니다. '하단 서명란에 주민등록번호·연락처·주소도 인쇄'를 체크하면 그 항목만 채워지고, 이때에도 이름은 인쇄하지 않습니다.
- 사건번호, 사건명, 당사자, 상대방: 사건의 표시 표에 들어갑니다.
- 수임범위: 형사는 수사단계, 제1심, 항소심, 상고심 버튼 또는 직접 입력. 민사·행정은 1심 사건, 항소심 사건, 상고심 사건 버튼 또는 직접 입력.
- 착수금: 3,000,000 또는 300만, 1억5천만처럼 쓰면 '금 300만원' 형태로 바뀌고 입력칸 아래에 확인 표시가 나옵니다. 부가가치세 별도 또는 포함을 고릅니다. 기본값은 원본 양식에 따라 형사는 별도, 민사·행정은 포함입니다.
- 착수와 동시 지급액(형사): 기본은 착수금 전액을 착수와 동시에 지급합니다. 체크를 풀면 동시에 지급할 금액을 따로 입력합니다.
- 성공보수 문구(형사): 제4조 다항을 전체 삭선(기본), 삭선 없이, 넣지 않음 중에서 고릅니다. 다항의 성공보수 금액과 부가가치세 포함·별도는 그 아래 칸에 입력합니다. 비워 두면 빈칸으로 남습니다.
- 성공보수 지급 조건(형사): 무혐의, 무죄, 집행유예, 벌금, 영장기각 버튼을 여러 개 고를 수 있고('무혐의, 무죄 또는 영장기각 시'처럼 이어짐), 그 밖의 조건은 기타 칸에 직접 씁니다(예: 공소기각 시). 선택하지 않으면 다항에는 조건이 빈칸으로 남습니다. 이 조건은 다항과 특약의 성공보수 줄에 같이 쓰입니다.
- 성과보수(민사·행정): 제7조를 적용 또는 전체 삭선으로 고릅니다. 가항 ①②와 ③은 항목별로 삭선할 수 있고, ①②의 비율은 숫자만 쓰면 %가 붙습니다.
- 예치금, 출장 일당: 금액을 쓰면 문장에 들어가고, 비우면 밑줄 빈칸으로 남습니다.
- 특약사항: 성공보수 금액과 부가가치세 별도·포함을 입력하면 특약사항에 한 줄로 들어갑니다. 형사는 위 성공보수 지급 조건이 그 줄에 같이 들어가고, 민사·행정은 이 칸에서 지급 조건을 직접 씁니다. 기타 특약은 한 줄에 한 항목씩 씁니다.
- 작성일, 동의서: 동의서의 사건 표기와 의뢰인은 비우면 각각 사건번호와 사건명, 위임인 성명이 들어갑니다. 동의서 하단 의뢰인 서명줄에는 의뢰인 이름이 인쇄됩니다.
- 수임인 표기: 화면 아래쪽 접힌 메뉴에서 사무소와 변호사 표기를 바꿀 수 있습니다. 기본값은 원본 양식의 표기입니다.
- 예시 입력은 견본 값을 채워 모양을 보는 버튼이고, 모두 지우기는 두 번 눌러야 지워집니다. 본문 복사는 문서 글자만 복사합니다.


문제가 생기면

- 설치가 거절되면: 계정의 요금제나 조직 설정 때문에 파일 저장 기능이 허용되지 않는 경우입니다. 관리자에게 문의합니다.
- 워드 파일 저장 버튼이 눌리지 않으면: 화면에 나오는 안내 문구를 확인하고, 새로고침 후 다시 시도합니다.
- 워드에서 3쪽을 넘으면: 미리보기 상단의 '넘칠 수 있음' 경고를 확인하고 특약사항 등 긴 입력을 줄입니다.
- 바탕체가 없는 PC(예: 맥)에서는 글꼴이 대체되어 쪽 수가 달라질 수 있으니 사무실 윈도우 PC에서 확인합니다.


참고

- 작성기는 본인 계정에만 설치되는 개인 도구이고, 사용할 때 Claude를 호출하지 않아 사용량을 쓰지 않습니다.
- 입력한 내용은 화면 안에서만 처리되고 서버에 저장되지 않습니다.
- 양식 문구는 원본 사건위임계약서 PDF를 그대로 옮긴 것입니다. 아래 표기는 원본에 있는 그대로이며 작성기가 고치지 않습니다. 정정이 필요하면 담당 변호사의 판단을 받은 뒤 관리자에게 요청합니다.
  형사 제5조 ①의 '보증,' / 형사 제4조 다항의 '위 성공보수로 중' / 형사 제6조의 '고의 중과실'
  민사·행정 제8조 ⑤의 '제2항의 예치금'(예치금은 같은 조 ③에 있음) / 민사·행정 제12조의 '6개월 이내 갑의 반환요청' / 민사·행정 동의서의 '경과 함에'
- 쪽 수는 LibreOffice 변환으로 3쪽을 확인했습니다. 실제 워드와 한글에서의 쪽 수는 사무실 PC에서 처음 한 번 저장해 확인하시기 바랍니다.
