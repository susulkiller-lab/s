진앤솔 마케팅 측정 프로그램 설치 안내 (윈도우)

1. 이 압축 파일을 풀고 'setup.bat'을 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 [추가 정보] -> [실행]
   - 설치 중 "이 앱이 디바이스를 변경하도록 허용" 창이 뜨면 [예]
2. 설치 도중 뜨는 창
   - GitHub 로그인 창: 브라우저로 로그인(저장소를 받기 위해 처음 한 번)
   - 크롬 탭 4개: Claude 확장 [Chrome에 추가] 후 로그인, ChatGPT/Gemini/Perplexity 로그인
   - 마지막에 열리는 검은 창(Claude Code): /login -> 구독 계정 선택 -> /chrome 에서 Status: Enabled 확인 -> /exit
3. 끝나면 바탕화면 '진앤솔 마케팅 리포트'를 더블클릭하면 측정부터 리포트(워드 파일)까지 자동으로 진행됩니다.

설치 위치: 문서\GitHub\s  (예전 PC에서 올려 둔 측정 기록도 함께 내려옵니다)
문제가 생기면 검은 창 화면을 캡처해 보내 주세요.
