진앤솔 업무사례 재가공기 설치 안내

블로그 성공사례 글을 홈페이지 '주요 업무사례' 원고로 바꾸고 검수하는 도구를
내 claude.ai 계정에 설치합니다. 설치는 한 번만 하고, 그다음부터는 웹 주소로 씁니다.


준비물
- Claude 유료 요금제 계정
- Claude 데스크톱 앱의 Code 탭 또는 Claude Code
- 이 폴더(jaegagong-kit) 전체
- (선택) 설정.json: 기존 재가공기의 변호사 목록·게시된 사례 목록 등을 그대로 옮기고 싶을 때


1단계. 설치 (Claude Code에서 1회)

1) Claude 데스크톱 앱의 Code 탭(또는 Claude Code)을 열고,
   작업 폴더로 이 jaegagong-kit 폴더를 선택합니다.
2) 설정까지 옮기려면 받은 설정.json 파일을 이 폴더 안에 넣어 둡니다.
3) 입력창에 아래 한 줄을 입력합니다.

   재가공기 설치해줘

4) 게시나 저장을 허용할지 묻는 창이 뜨면 허용합니다.
5) 마지막에 나오는 재가공기 주소를 즐겨찾기에 추가합니다.


2단계. 사용 (매번, 웹에서)

1) 즐겨찾기한 주소를 엽니다. Claude Code는 더 필요 없습니다.
2) 처음 '실행'을 누를 때 뜨는 Claude 사용 허용 창을 허용합니다.
3) 화면 위쪽 '사용법' 탭에 전체 사용법이 있습니다.
4) 설정을 옮기지 않았다면 설정 탭에서 변호사 목록부터 채웁니다.


설정을 옮기는 법 (보내는 사람)

1) 기존 재가공기 주소를 열고 설정 탭 맨 아래 '설정 내보내기·가져오기'에서
   '내보내기(복사)'를 누릅니다. (편집자에게만 보입니다)
2) 메모장을 열어 붙여 넣고 '설정.json'이라는 이름으로 저장합니다.
3) 이 키트 폴더와 함께 받는 사람에게 전달합니다.

설정 파일 없이 설치했어도, 나중에 받는 쪽 재가공기의 같은 칸에
설정.json 내용 전체를 붙여 넣고 '가져오기'를 누르면 옮겨집니다.


새 판으로 바꾸기

관리자에게 새 키트 폴더를 받아, 같은 방법으로 폴더를 연 뒤
"재가공기 업데이트해줘"라고 입력하고 기존 주소를 알려 줍니다.
주소와 저장된 작업·설정은 그대로 유지됩니다.


참고
- 글 생성은 본인 Claude 사용량으로 처리됩니다. 한 편에 3~4번 호출하고, 다시 쓰기를 누르면 더 늘어납니다.
- 팀원과 함께 쓰려면 주소 화면의 공유 메뉴에서 이메일로 초대합니다.
  작업 저장·게시 기록은 '참여자' 이상, 설정 변경은 '편집자'여야 합니다.
- 블로그 원고와 사건 기록은 작업한 컴퓨터의 브라우저에만 남고, 공용 저장소에 올라가지 않습니다.
- 공개 링크로 공유하지 않습니다.
- 홈페이지에 올리기 전에는 반드시 담당 변호사 검토를 받습니다.
