상담일지 정리 설치 안내

상담 직후 칸을 채우면 변호사님께 보고할 일지 텍스트를 만들어 주고, 상담 기록을 보관해 경로별 통계와 엑셀 내보내기까지 해 주는 개인 도구입니다. 설치는 Claude Code에서 한 번만 하고, 이후에는 웹 주소로 씁니다.


준비물
- Claude 데스크톱 앱(Code 탭) 또는 Claude Code를 쓸 수 있는 본인 계정
- 이 폴더(consult-log-kit) 전체

별도로 추가할 커넥터는 없습니다.


1단계. 설치 (Claude Code에서 1회, 약 2분)

1) Claude 데스크톱 앱의 Code 탭(또는 Claude Code)을 열고 작업 폴더로 이 consult-log-kit 폴더를 선택합니다.
2) 입력창에 아래 한 줄을 입력합니다.

   상담일지 설치해줘

3) 게시 허용을 묻는 창이 뜨면 허용합니다.
4) 마지막에 나오는 주소를 즐겨찾기에 추가합니다. 이 주소가 본인의 상담일지이며 본인만 열 수 있습니다.


2단계. 첫 사용 (웹에서)

1) 즐겨찾기한 주소를 엽니다. Claude Code는 더 필요 없습니다.
2) 칸을 채우고 정리하기를 처음 누를 때 Claude 사용 허용 창이 뜹니다. 허용합니다.
3) 정리가 끝나면 기록이 자동 보관됩니다. 다음 상담은 새 상담 버튼을 누르고 시작합니다.
4) 기록·통계 탭의 엑셀로 내보내기를 처음 누르면 파일 저장 확인 창이 뜹니다. 저장을 허용합니다.

자세한 사용법은 사용설명서.txt를 보십시오.


3단계. 기존 상담 기록이 있을 때 (선택)

예전에 쓴 일지 텍스트가 남아 있으면 기록함에 한꺼번에 넣을 수 있습니다.

1) 설치할 때 쓴 Claude Code 창(또는 새 창, 작업 폴더는 같은 consult-log-kit)에 일지 텍스트를 붙여넣습니다.
2) 같이 "기록함에 넣어줘"라고 입력합니다.
3) 다 넣고 나면 Claude가 넣은 건수, 경로별 건수, 확인이 필요한 건을 알려 줍니다.

적혀 있지 않은 항목은 추측해서 채우지 않고 비워 둡니다. 날짜가 맞지 않거나 연도가 없는 건은 먼저 물어봅니다.


참고
- 상담일지는 본인만 보는 개인 도구입니다. 기록함도 본인 기록만 쌓입니다.
- 정리하기는 본인 Claude 사용량으로 처리됩니다. 누를 때마다 Claude를 한 번 호출합니다.
- 이름과 전화번호가 저장되므로 공개 링크로 공유하지 않습니다.
- 여러 직원이 한 기록함을 같이 쓰려면 사용설명서의 '여럿이 함께 쓰려면' 항목을 먼저 읽으십시오.
